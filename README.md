# QuickCut AI

Tell it what to edit. AI does the rest.

## Overview

QuickCut AI is an AI-powered video editing platform that leverages Claude AI to help users create professional video edits. Upload your media, describe what you want, and let QuickCut AI handle the heavy lifting.

### Features

- **AI-Powered Editing**: Use natural language to describe your editing vision
- **Smart Media Analysis**: Automatically analyze uploaded media for best moments
- **Quick Export**: Export videos in multiple formats and qualities
- **Interactive Timeline**: Visual timeline for easy clip arrangement
- **Live Chat**: Talk to QuickCut Director AI in real-time
- **Multiple Editing Modes**: Auto, Smart, Manual, Meme, Shorts, Cinematic, Music Sync
- **Aspect Ratio Support**: 16:9, 9:16, 1:1, 4:3
- **Real-time Collaboration**: Share projects and edits with team members

## Technology Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: Supabase PostgreSQL
- **Storage**: Supabase Storage
- **AI**: Anthropic Claude Sonnet 4.6
- **State Management**: Zustand
- **HTTP Client**: Axios

## Prerequisites

- Node.js 18+ and npm
- Supabase account
- Anthropic API key
- Modern web browser
